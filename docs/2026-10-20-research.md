# Return Window — consumer research note

**Date:** 2026-10-20
**Decision:** Maintain a small, local return-deadline tracking experiment; do not claim validated demand, novelty, or willingness to pay.

## Evidence and limits

- The U.S.-oriented [NRF 2025 Retail Returns Landscape](https://nrf.com/research/2025-retail-returns-landscape), published October 15, 2025, estimates 19.3% of online sales are returned and reports 82% say free returns are important. The landing page gives no sample details; these figures do **not** measure missed return deadlines.
- A [Reddit discussion](https://www.reddit.com/r/shoppingaddiction/comments/1sg9896/anyone_else_constantly_miss_or_forget_return/) observed as six months old (approximately April 2026; exact date unverified) contains several self-selected anecdotes about forgetting return windows and using calendar reminders. It is not a prevalence estimate. Do not reproduce community text.
- [Return Tracker's App Store listing](https://apps.apple.com/us/app/return-tracker/id6749532557), observed October 20, 2026, advertises receipt OCR, reminders, and custom policies. Its undated listing and limited reviews do not establish adoption or effectiveness. Existing tools rule out an unqualified novelty claim.
- Older subscription-tracker and calendar sources show spreadsheet/CSV, notes, and calendar workflows persist, but provide no reliable benchmark of automatic detection or savings. They are adjacent workflow context, not proof people will pay for Return Window.

## Product hypothesis

The private `enchantered/return-window-2026-10-20` project uses a manually maintained CSV with an explicit, user-verified `return_by` date. It presents upcoming and overdue open entries and can export an iCalendar file locally. It does not infer retailer policies or dates, upload data, or send automatic notifications. A calendar export is not the same as verified calendar import or an alert. Keep examples synthetic; do not copy community users' text or source assets.

This is a hypothesis about a lightweight manual workflow, not a claim of differentiation or willingness to pay. Compare it with **SubscriptionCheck** and **ClipboardPantry** as candidate directions only; the comparison is not a validated ranking. U.S. evidence cannot establish demand in India, which remains unvalidated.

## Validation gate

Test with five consenting users before making broader claims. Observe (1) whether users can enter a purchase without help, (2) whether each deadline is checked against the retailer's actual terms, (3) whether exported events can actually be imported into their calendar apps, and (4) whether they return to the workflow weekly. No such five-user validation has yet been completed.

## Run status

The October 20 run passes eight Return Window tests, compilation checks and CLI smoke commands. The tests cover inclusive deadlines, overdue/completed statuses, malformed CSV, duplicate IDs, chronology, Unicode/calendar injection escaping, required UTC event timestamps, early years and year-9999 overflow. This does not establish real-calendar import compatibility, consumer use or willingness to pay. Commit and private push are verified separately in the final run delivery.
